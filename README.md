# ADsP 공부 기록

목표: 2027년 1분기 ADsP 합격 (SQLD · AICE Associate와 함께)
방식: 이론 조금 → 내가 이해한 대로 써 보기 → 틀린 이해 바로잡기 → 문제 (예시는 '마트 손님' 하나로 통일)

## 시험 형식
| 항목 | 내용 |
| --- | --- |
| 문항 | 객관식 50문항, 90분, 종이 시험 |
| 과목 | 1과목 데이터 이해 10 · 2과목 데이터 분석 기획 10 · **3과목 데이터 분석 30** |
| 합격 | 평균 60점 이상 + 과목별 40점 이상 |
| 일정 | 1년 4회 (2026년 2·5·8·10월) → 2027 첫 회차는 dataq.or.kr 공지 확인 |
| 교재 | 민트책 (데이터에듀), 2027년판 |
